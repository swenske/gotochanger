    Latency

    These are simulated delays for exercising backup software against realistic tape-library timing - not measurements of real hardware. Applies to the whole virtual tape library (all logical libraries share one timing model).

    Enable
    Drive delays
    Robotic arm delays

    Durations accept units like "500ms", "2s", "1m" (0s to 5m).

    Cleaning Tapes

    Cleaning-cartridge management for drive-head cleaning cycles. Applies to the whole virtual tape library. Cleaning tapes are universal: they have no specific tape type or model and work with every supported drive family. There's no separate "start cleaning" action - loading a cleaning tape into a drive (the same Load action used for any cartridge) is itself a manual cleaning cycle; it's automatically ejected and returned to its slot once the cycle completes.

    Enable
    Operating mode
    Tunables

    Duration accepts units like "500ms", "2s", "1m" (0s to 30m).

    Cleaning tape pool

    Up to 5 cleaning cartridges, barcode format "00001CLN". Hover a tape for its remaining cleaning cycles. A tape's expired state requires manual removal: open its magazine's storage door, stage a pickup for its slot, close the door, then delete it from the Outside Library Tapes panel on the dashboard.

    Reset
    
      
    Warning: this permanently deletes the entire VTL - every magazine, mailbox, drive, logical library and tape set, all settings (latency, cleaning, offsite, SNMP, etc.), and all user accounts and API tokens. You will need to set a new Admin password afterward, exactly as on a brand new install. A safety backup is taken automatically first and can be restored via Admin > Backup if this was a mistake. The service restarts to apply the reset and will be briefly unreachable.
